# Битва жуков — онлайн-дуэль (инструкция по запуску)

В папке четыре файла:

| Файл | Что это |
|---|---|
| `index.html` | сама игра (одним файлом, шрифт внутри) |
| `database.rules.json` | правила безопасности базы Firebase |
| `firebase.json` | настройки для Firebase Hosting (нужны только для варианта Б) |
| `README.md` | эта инструкция |

Без настройки Firebase игра работает как раньше (весь офлайн-режим). Вкладка **ОНЛАЙН** покажет, что онлайн не настроен.

---

## Шаг 1. Создай проект Firebase (бесплатно)
1. Зайди на https://console.firebase.google.com → **Добавить проект** (Google Analytics можно выключить).
2. **Сборка → Authentication → Начать → Способ входа → Электронная почта/пароль → Включить → Сохранить.**
3. **Сборка → Realtime Database → Создать базу данных** (любой регион, режим «тестовый» подойдёт — правила мы сейчас заменим).
4. Вкладка **Правила** в Realtime Database: удали всё, вставь содержимое `database.rules.json` и нажми **Опубликовать**.

## Шаг 2. Вставь ключи в игру
1. **Настройки проекта (шестерёнка) → Ваши приложения → значок `</>` (Веб)** → зарегистрируй приложение → скопируй `firebaseConfig`.
2. Открой `index.html` в любом текстовом редакторе, найди в самом начале скрипта блок:
```js
const FB_CFG={apiKey:"",authDomain:"",databaseURL:"",projectId:"",appId:""};
```
и впиши свои значения. **`databaseURL` обязателен** — он есть на странице Realtime Database вверху (вида `https://ИМЯ-default-rtdb.europe-west1.firebasedatabase.app`). Если в `firebaseConfig` его нет, скопируй со страницы базы.

## Шаг 3. Выложи игру (выбери один вариант)

### Вариант А. GitHub Pages (проще всего)
1. Создай репозиторий на GitHub и загрузи в корень все файлы из папки.
2. **Settings → Pages → Source: Deploy from a branch → main / (root) → Save.**
3. Через минуту игра откроется по адресу `https://ТВОЙ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.
4. **Важно:** в Firebase открой **Authentication → Settings → Authorized domains → Add domain** и добавь `ТВОЙ_ЛОГИН.github.io`. Без этого вход не заработает.

### Вариант Б. Firebase Hosting (+ автодеплой с GitHub)
```
npm install -g firebase-tools
firebase login
firebase init        # выбери Hosting и Realtime Database; public directory: .   (index.html НЕ перезаписывай)
firebase deploy --only hosting,database
```
Адрес будет `https://ИМЯ-ПРОЕКТА.web.app` (домен добавится в разрешённые автоматически).
Чтобы игра обновлялась сама при каждом `git push`: `firebase init hosting:github` — он сам создаст workflow и секрет.

## Шаг 4. Как играть
1. Вкладка **ОНЛАЙН → РЕГИСТРАЦИЯ**: придумай логин (латиница, цифры, `_`, 3–16 символов) и пароль (от 6 символов). **Пароль восстановить нельзя** — запомни его.
2. Нажми **АВАТАРКА** и выбери картинку из галереи (она сожмётся до 64×64).
3. У тебя есть личный **ID из 6 цифр** (кнопка «СКОПИРОВАТЬ ID»). Отправь его другу.
4. Друг вводит твой ID в поле **ПОЗВАТЬ В БОЙ** → тебе приходит приглашение → **ПРИНЯТЬ**.
5. В лобби оба выбирают бойца и жмут **ГОТОВ!** — начинается дуэль до двух побед.

### Равные условия
В дуэли у всех бойцов **одинаковые здоровье (120), скорость и урон**. Улучшения, ранги, предметы, критические удары и вампиризм **отключены**. Решают только набор приёмов, ловкость и ульта. Игрок, который пригласил, стоит слева, приглашённый — справа (стик и кнопки работают одинаково для обоих).

### Рейтинг
За победу/поражение считается рейтинг (как в шахматах, старт — 1000). Таблица «Лучшие игроки» — в той же вкладке.

## Как это устроено (коротко)
* Аккаунты — Firebase Authentication. Логин превращается в служебную почту `логин@bugfight.app`, пароль хранит Google (в игре его нет).
* Аватарка (64×64, ~3 КБ) лежит в Realtime Database в профиле игрока — платная Firebase Storage не нужна.
* Бой идёт **синхронно у обоих игроков**: по сети передаются только нажатия (с небольшой задержкой ~0,13 с), а сама симуляция одинаковая на обоих телефонах. Поэтому у хоста нет преимущества в пинге. Если у соперника лаг, у тебя появится надпись «ЖДЁМ СОПЕРНИКА…».
* Если соперник вышел или пропал больше чем на 12 секунд — тебе засчитывается победа. Кнопка паузы в дуэли открывает меню «СДАТЬСЯ / ВЕРНУТЬСЯ» (сам бой не останавливается).

## Если делаешь APK
Firebase Auth не работает со страниц `file://`. В WebView загружай **https-адрес** игры (GitHub Pages или Firebase Hosting):
```kotlin
wv.settings.javaScriptEnabled = true
wv.settings.domStorageEnabled = true
wv.loadUrl("https://ТВОЙ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/")
```
(офлайн-режим при этом тоже работает, пока есть кэш; для постоянной работы без интернета оставь отдельную офлайн-сборку).

## Частые вопросы
* **«Нет соединения»/онлайн не открывается** — проверь интернет и что в `index.html` вставлены все ключи, особенно `databaseURL`.
* **«Нет доступа: проверь правила»** — правила из `database.rules.json` не опубликованы.
* **Вход выдаёт ошибку домена** — добавь адрес сайта в Authentication → Settings → Authorized domains.
* **Приглашение не приходит** — другу нужно быть в игре на вкладке меню (приглашение живёт 2 минуты).
* **Лимиты** — бесплатного тарифа Firebase хватит на сотни игроков: в бою передаются только нажатия (около 30 мелких записей в секунду на игрока).
